## Getting Started

Before running this, make sure npm is installed on the system, and added to the path environment variables in the OS.

First, make sure all of the correct node packages are installed. These packages are defined in the packages.json file, and running the following command should install all dependencies required:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

This will spin up a local server to host the website locally on the computer.
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
